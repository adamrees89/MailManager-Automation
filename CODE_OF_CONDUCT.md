# Code of Conduct

All contributors are expected to follow this Code of Conduct.

Be respectful:
- Treat others with respect and kindness.
- Assume good intent and be constructive in feedback.

No harassment:
- Harassment, hate speech, or abusive language is not tolerated.

Reporting issues:
- If you experience or witness unacceptable behavior, please contact the maintainers via email or open a private issue.

Consequences:
- Violations may result in warnings, PR rejections, or removal from the project depending on severity.

This project follows the Contributor Covenant principles.
